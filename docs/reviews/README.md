# ARE reviews

This directory contains evidence-led product and release reviews for the
Abrahamic Reference Engine.

Each review must identify:

- the frozen artifact and commit;
- one decision question;
- acceptance criteria;
- a claim/evidence ledger;
- independent evidence, outcome, and safety/portability findings;
- conditional disruption when the initial findings materially converge;
- a decision with limits, unresolved evidence, and expiry triggers.

These records are governance artifacts, not theological authority or specialist
certification.
